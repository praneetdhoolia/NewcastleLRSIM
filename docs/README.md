# docs/ — where each document lives and which ones are generated

Four files stay at the repo root because they are the operational entry points:
[`README.md`](../README.md) (data-package guide), [`CLAUDE.md`](../CLAUDE.md)
(conventions and hard constraints), [`STATUS.md`](../STATUS.md) (the board — read
at session start) and [`DECISIONS.md`](../DECISIONS.md) (**the single source of
truth for every value that is not observed**). Everything else is here.

| | Document | Generated by | Edit by hand? |
|---|---|---|---|
| **design/** | [`newcastle-lr-proposal.md`](design/newcastle-lr-proposal.md) — the research design: scenarios, hypotheses, tests, appendices | — | Only to correct the record, and note it in `DECISIONS.md` §2 |
| | [`project-flow.html`](design/project-flow.html) — one-page orientation: P0–P7 flow, data layers, scenario matrix, pre-registered metrics | — | **Plan, not result.** Its run-time figures are placeholders |
| **reference/** | [`CONFIG_REFERENCE.md`](reference/CONFIG_REFERENCE.md) — all 208 registry fields with units, provenance and sweep | `python src/registry/render_docs.py` | ❌ **never** — `check_package.py` fails on staleness |

## Two rules that keep this directory honest

1. **A generated document is never edited by hand.** Four of the eight files above
   are outputs of a committed script, and two of them are gated: `check_package.py`
   re-runs `render_docs.py --check` and fails if `CONFIG_REFERENCE.md` has drifted
   from the registry. Change the registry, then regenerate, in the same commit.
2. **Narrative belongs in `DECISIONS.md`, not here and not in `STATUS.md`.** The
   session log exists because 944 lines of dated narrative had accumulated inside
   `STATUS.md`, which made the one file that is supposed to be readable at session
   start the longest file to read. Record the decision and its rationale in
   `DECISIONS.md`; update the board line in `STATUS.md` that it makes wrong.

**Nothing in this repository is a result.** No scenario has been run to a
reportable state — see `STATUS.md`.
